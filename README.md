# Paste Ops

Apply `file:`, `patch:`, `rename:`, `delete:`, and `dir:` operations inside code block from the clipboard.

## Command

Run:
CTRL+ALT+V

## How to use:
Copy the whole response from LLM that contain `file:`, `patch:`, `rename:`, `delete:`, and `dir:` inside the code block then paste it as shortcut above, vscode handle the rest then you review what change and accept it or not.
